┌───────────────────────────────────────────────────────────────────────────┐
│                         WHY THIS ARCHITECTURE?                             │
└───────────────────────────────────────────────────────────────────────────┘

Problem: 8+ hours of scraping
❌ Serverless functions → Max 300s timeout
❌ Browser tab → Can't run for hours
❌ Chained functions → Unreliable, expensive
✅ Background worker → No timeout, dedicated resources

Problem: 1,500+ click interactions
❌ Static scraping → Need dynamic rendering
❌ API endpoints → No API available
✅ Stagehand + Playwright → AI-powered click & extract

Problem: Salesforce dynamic loading
❌ Simple HTTP → Content not rendered
❌ Fast scraping → Missing data
✅ Wait + AI extraction → Full content capture

Problem: 8-hour cost
❌ Cloud browsers → $48+ per scrape
✅ Local Playwright → $5-10/month unlimited
